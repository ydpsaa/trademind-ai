# DAXIS Quant Lab v0.2.0

Изолированная исследовательская сборка для существующего `ydpsaa/trademind-ai`. Это продолжение Quant Core v0.1.0: не новый production-сайт, не выполнение ордеров и не доказательство прибыльности. Вся математика, импорт и расчёты браузерного интерфейса работают локально.

## Запуск

Открыть `preview/index.html` в обычном браузере после распаковки (готовый `quant-lab.bundle.js` включён). Самодостаточная версия `DAXIS_Quant_Lab_v0.2.0.html` содержит все JS и CSS внутри файла и не требует сервера. Выбрать модель → `Run sandbox backtest`; для Market Making → `Calculate theoretical quote`; для проп-модели → `Run probability model`.

Для воспроизводимой сборки на Node 22+ и TypeScript 5.x:

```sh
tsc -p tsconfig.quant.json
node --test tests/*.test.cjs
node scripts/build-preview.cjs
```

Браузерный тест: `python tests/browser_test.py` при установленном Playwright и Chromium (путь `/usr/bin/chromium` в тесте можно изменить под ОС). Тест загружает HTML и JS в память браузера, а не проверяет сетевую публикацию или Next.js-маршрут. Проверки использовали синтетические OHLC, имитацию строк провайдера и контрольные математические примеры. 48 Node-тестов + 11 браузерных проверок прошли; `docs/TEST_RESULTS.txt`, `docs/BROWSER_RESULTS.txt`.

CSV — строгий формат `symbol,time,open,high,low,close,volume` (без кавычек/встроенных разделителей, volume может быть пустым), UTC ISO или epoch ms, равномерный интервал, до 8 активов и 1200 свечей на актив. Загруженный пользователем файл всегда непроверенный Sandbox. Не переносить его в журнал как реальную сделку. Backtest использует закрытие для сигнала, следующее открытие для исполнения, модельную комиссию/проскальзывание; нет внутрисвечных стопов, брокерской маржи, FX, контрактных множителей, финансирования и рыночной ёмкости. Fills ≠ закрытые сделки.

Prop: точный finite-horizon random walk доступен лишь для симметричных целочисленных границ и ±1R; Monte Carlo с IID возвратами не моделирует дневную просадку/трейлинг/выплату. Интервал — sampling error симуляции, не прогноз реальной вероятности прохождения. Введённая пользователем серия R не проверена.

См. `docs/QUANT_LAB_INTEGRATION.md` и `docs/CORE_INTEGRATION.md`. Никакие production-данные, API-ключи, реальные счета, Supabase migrations или order endpoints не затрагиваются. Сохранить изменения владельца, сверить пути и `AGENTS.md`, прочитать документацию установленного Next.js и только затем подключить защищённый маршрут, UI и реальные данные.
